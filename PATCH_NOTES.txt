모아루 v64.5.5 안정화 패치

적용 기준
- v64.5.4 위에 이 압축 파일의 폴더 구조를 그대로 덮어씁니다.
- GitHub Pages 배포 후 강력 새로고침을 합니다.
- 설치형 PWA가 이전 캐시를 계속 쓰면 앱을 완전히 종료한 뒤 다시 실행합니다.

수정 내용
- 실제 마지막 CSS가 하단 메뉴를 72px로 되돌리던 충돌을 제거하고 최종 높이를 56px로 고정
- 작은 화면에서 미니 상점 아이콘이 카드 위로 치우치지 않도록 카드 전체 세로 중앙에 배치
- 상점·빈 화면의 마름모와 + 배지를 절대 중심 좌표로 정렬
- 15초 보관함 동기화 결과가 같을 때 상태 이벤트와 화면 전체 재렌더링을 생략
- 실제 상품 변경으로 다시 그릴 때 스크롤 위치를 유지하고 진입 애니메이션을 반복하지 않음
- 상품 사용 상태를 Apps Script와 Firebase 양쪽에 동기화
- 사용 버튼 중복 클릭 방지와 ITEM_NOT_AVAILABLE 한글 오류 안내 추가
- 로그인 직후 Firebase의 첫 프로필·대화방 응답을 기다린 뒤 첫 대화 화면을 표시해 기본 프로필 깜빡임 제거
- Document PiP 요청 크기를 350×680px로 변경

유지 사항
- 일반 팝업 크기와 설치형 PWA 크기는 변경하지 않았습니다.
- manifest.webmanifest는 변경하지 않았습니다.
- Apps Script 보관함 도입 전에 Firebase에만 생성된 구형 상품은 초기화 대상이며 자동 복구하지 않습니다.

검증
- 정적 검사 통과
- JavaScript 56개 문법 검사 통과
- 자동 기능 테스트 38개 통과
- Apps Script 8개 파일 구성 및 문법 검사 통과
- 350×680 실제 전체 CSS 순서 렌더링에서 상점 아이콘·보관함 배지·56px 하단 메뉴·가로 넘침 없음 확인
