모아루 v64.5.3 패치

적용 기준
- v64.5.2 위에 이 폴더의 파일과 폴더 구조를 그대로 덮어씁니다.
- GitHub Pages 배포 후 강력 새로고침을 합니다.
- 기존 설치형 PWA가 이전 캐시를 계속 쓰면 앱을 완전히 종료한 뒤 다시 실행합니다.

수정 내용
- 설치형 PWA 첫 실행에서 창 크기 조정이 무시되더라도 여러 번 재시도
- 설치형 PWA를 화면 오른쪽 아래로 배치
- 설치형 PWA가 넓게 열려도 하단 메뉴 구조 유지
- 상단 및 검색창 돋보기 세로 중앙 정렬
- 대화 입력창 첨부 + 버튼 확대 및 중앙 정렬
- 하단 대화/도구/과제/쇼핑/설정 메뉴 높이 축소
- 보낸 말풍선의 밝은 외곽 링과 추가 그림자 제거
- 공통 모달, 알림, 관리자 공지, 타로 닫기 × 중앙 정렬
- 타로 제목/날짜/닫기 버튼 세로 중심 정렬

브라우저 제한
- 데스크톱 Chrome 설치형 PWA의 최소 외곽 폭과 제목 표시줄 버튼은 Chrome이 관리합니다.
- 설치형 PWA를 항상 위로 고정할 수 없으며, 항상 위 기능은 Document PiP에서만 가능합니다.

검증
- 정적 검사 통과
- JavaScript 56개 문법 검사 통과
- 자동 기능 테스트 37개 통과
- 400×740 브라우저 렌더링 점검 완료
