모아루 v57 적용 안내

1. GitHub 저장소에는 ZIP 안의 파일을 경로 그대로 덮어씁니다.
2. Apps Script에서는 docs/apps-script/Code.gs와
   docs/apps-script/coin-shopping-extension.gs를 각각 전체 교체합니다.
3. Apps Script 웹 앱을 새 버전으로 다시 배포합니다.
4. Firebase 규칙은 database.rules.json을 사용할 때만 교체합니다.

변경 내용
- 로그인 시트의 가입자 닉네임 명단을 선물하기와 관리자 대상 선택에서 공통 사용
- 선물받을 사용자 닉네임 검색 추가
- 예전 문자열형 프로필 이미지와 여러 프로필 필드명 호환
- 새 메시지에 발신자 프로필 이미지를 함께 저장하고 기본 이미지는 모아루 캐릭터로 표시
- PC/웨일북 팝업 기본 가로폭 380px로 축소
- 좁은 화면에서 '무음', '공유' 같은 단어가 글자 중간에서 끊기지 않도록 조정

보안
- user_directory 응답에는 user_id와 nickname만 포함합니다.
- 로그인 시트의 비밀번호 등 인증 정보는 브라우저에 전달하지 않습니다.
