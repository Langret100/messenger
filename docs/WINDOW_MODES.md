# 창 실행 방식

## 1. 구석창 (기본)
`window.open()`의 `popup=yes` + 최소 UI 힌트를 사용합니다. 브라우저가 허용하는 범위에서 탭/툴바를 줄이고 독립 창으로 엽니다. 주소/출처 표시를 완전히 숨긴다고 보장할 수는 없습니다.

- 기본 크기 390x680
- 마지막 위치/크기를 localStorage에 저장
- 재실행 시 저장 위치/크기 요청
- 동일 이름 창을 재사용하여 중복 창 방지
- 원래 탭을 닫아도 일반적으로 팝업은 독립적으로 유지되지만 브라우저 정책에 따라 차이가 있을 수 있습니다.

## 2. 항상 위 모드
Document Picture-in-Picture. 항상 위에 유지되지만 브라우저가 보안용 상단 UI를 표시합니다.

## 3. PWA
선택 설치. Window Controls Overlay를 지원하는 설치형 Chromium PWA에서는 제목 영역을 더 줄일 수 있습니다. 설치 없는 기본 사용 조건에는 포함하지 않습니다.

## 4. 현재 창
팝업 차단/미지원 시 마지막 폴백.
