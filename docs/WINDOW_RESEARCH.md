# 설치 없는 소형 창 방식 조사 요약

## 결론
설치 없는 웹 링크 조건에서 가장 실용적인 기본 모드는 `window.open()`의 `popup` 요청입니다. 독립 창이며 크기/초기 위치를 지정할 수 있고, 원래 탭과 DOM을 공유하지 않습니다. 다만 주소/출처 UI의 완전 제거는 브라우저가 보안상 보장하지 않습니다.

## 적용 우선순위
1. 일반 minimal popup — 기본
2. Document Picture-in-Picture — 항상 위가 필요할 때
3. PWA + Window Controls Overlay — 설치를 허용하는 사용자의 선택 기능
4. 현재 탭 — 팝업 차단/미지원 폴백

## 조사에서 제외한 우회
- about:blank/blob/data URL로 주소를 속이거나 가리는 방식: 보안 UI를 확실히 제거하지 못하며 출처 표시가 더 혼란스러울 수 있어 사용하지 않음.
- Fullscreen API: 독립된 작은 창이 아니므로 목적과 불일치.
- kiosk/--app 명령줄: 사전 설치/사용자 환경 설정이 필요해 "링크만 접속" 조건과 불일치.
- 확장/네이티브 앱: 더 강력하지만 설치 없는 조건과 불일치.

## 구현
`js/adapters/window-mode.js`에 모든 창 방식이 집중되어 있어 향후 브라우저 정책 변화 시 이 파일만 교체하면 됩니다.
