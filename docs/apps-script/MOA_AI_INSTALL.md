# 모아와 대화하기 Apps Script 설치 / 제거

## 구조 원칙
- 기존 미나용 `대화` 시트와 **연결하지 않습니다.**
- 모아의 기본 회화는 클라이언트 `js/ai/moa-chat-engine.js`에 들어 있습니다.
- 새 학습은 모아 전용 시트에만 누적됩니다.
- 화면에 보이는 대화 내역은 **기기 IndexedDB**에만 저장하며 서버/Firebase에 저장하지 않습니다.
- Firebase Realtime Database/Rules 추가 작업은 없습니다.

## 설치
Apps Script 편집기에서 `MOA_CHAT.gs`, `MOA_LEARNING.gs` 두 파일을 추가하고 이 패치의 같은 이름 내용을 붙여넣습니다.

`Code.gs`의 `doPost(e)` switch에는 패치본의 `MOA_CHAT_INTEGRATION_START` ~ `MOA_CHAT_INTEGRATION_END` 블록만 추가합니다.

그 뒤 `배포 → 배포 관리 → 수정 → 새 버전 → 배포`합니다. 기존 웹앱 URL을 그대로 사용할 수 있습니다.

## 자동 생성되는 전용 시트
- `모아_대화`: 모아 전용 공용 학습 데이터
- `모아_표현학습`: 평소 대화에서 긍정된 질문 표현과 이미 나온 답변의 연결 강도
- `모아_학습후보`: 사용자가 자연스럽게 정정한 내용을 검토 후보로 축적
- `모아_개인기억`: 좋아하는 것/싫어하는 것/별명/취미처럼 제한된 사용자별 기억

기존 `대화` 시트는 모아가 읽지도 쓰지도 않습니다.

## 자연학습 방식
사용자는 일일이 가르치기 버튼을 누를 필요가 없습니다.

- 모아의 답 뒤에 `맞아`, `응 맞아`, `고마워` 같은 반응 → 앞 질문 표현과 답변의 연결을 긍정 학습
- 같은 builtin 질문/답 조합이 2회 이상 긍정 → 모아 전용 표현학습 후보로 이후 검색에 활용
- `아니`, `그게 아니라`, `틀렸어` 같은 정정 → `모아_학습후보`에 자동 축적
- 정정 내용은 장난/오정보 방지를 위해 자동 공용 정답으로 즉시 승격하지 않음

## 완전 제거 방법
1. Apps Script에서 `MOA_CHAT.gs`, `MOA_LEARNING.gs` 삭제
2. `Code.gs`의 `MOA_CHAT_INTEGRATION_START` ~ `MOA_CHAT_INTEGRATION_END` 블록 삭제
3. 웹앱 새 버전 재배포
4. 학습 데이터도 버릴 경우 `모아_대화`, `모아_표현학습`, `모아_학습후보`, `모아_개인기억` 시트 삭제
5. 클라이언트 제거는 `js/features/moa-chat.js` 상단의 제거 안내대로 처리

기존 `대화` 시트, 기존 미나 기능, Firebase는 건드릴 필요가 없습니다.


## v75 자동학습 정리 정책

자동 정리는 **달력 날짜를 기준으로 삭제하지 않습니다.** 프로그램을 오래 사용하지 않으면 `moa.activity.serial.v1` 활동 카운터도 증가하지 않으므로 학습 데이터는 그대로 보존됩니다.

정리 대상은 자동 생성 데이터인 `모아_표현학습`, `모아_학습후보`뿐입니다. `모아_대화`의 확정/수동 학습과 `모아_개인기억`은 자동삭제하지 않습니다.

- 실제 모아 서버 상호작용이 800회 이상 누적된 뒤에도 약한 자동학습만 1차 `dormant` 처리
- 휴면 처리 이후 다시 800회 이상의 실제 활동이 누적됐는데도 여전히 약하면 삭제
- 표현학습은 전체 평균 반응량의 1/4 미만이면서 긍정도가 낮은 항목만 대상
- 학습후보는 반복 1회 이하, 신뢰도 0.45 미만인 미검증 후보만 대상
- `review`, `approved`, `protected`, `pinned` 후보는 자동삭제 제외
- 기존 데이터에 활동 기준값이 없으면 처음 유지보수에서 삭제하지 않고 현재 활동값만 기록

### 주 1회 자동 유지보수 켜기
Apps Script 편집기에서 `moaInstallMaintenanceTrigger_()`를 **한 번만 직접 실행**하세요. 동일 유지보수 트리거가 있으면 먼저 정리한 뒤 주 1회 트리거 하나만 생성합니다.

자동 유지보수를 끄려면 `moaRemoveMaintenanceTrigger_()`를 한 번 실행하면 됩니다.
