# 모아와 대화하기 — 최종 통합 구조 / Apps Script 적용

> 이 문서는 설명용입니다. Apps Script 편집기에 `MOA_AI_INSTALL.md`를 넣지 않습니다.
> 실제 Apps Script 적용 파일은 `Code.gs`, `MOA_CHAT.gs`, `MOA_LEARNING.gs` 3개입니다.

## 구조 원칙
- 기존 미나용 `대화` 시트와 **연결하지 않습니다.** 완전히 분리합니다.
- Firebase Realtime Database 읽기/쓰기/listener를 모아 AI 때문에 추가하지 않습니다.
- 화면에 보이는 모아 대화 원문은 사용자 기기의 IndexedDB에 최근 120개까지만 보관합니다.
- 공용 학습에는 대화 원문 전체를 저장하지 않습니다. 검증된 표현 반응, 정정 후보, 제한된 개인기억, 짧은 주제/연관관계만 저장합니다.
- 클라이언트는 `moa-dialogue-core.js`가 소재/행동/결과/감정/질문/문맥을 분석하고, `moa-chat-engine.js`가 검색·도구·학습·응답을 조정합니다.
- 특정 주제(축구/음식 등)를 계속 하드코딩하는 방식은 중심 구조로 사용하지 않습니다. 하드코딩 회화는 초기 안전망일 뿐입니다.

## Apps Script 적용
1. 기존 프로젝트의 `Code.gs`를 패치본으로 교체합니다.
2. `MOA_CHAT.gs`, `MOA_LEARNING.gs`를 추가 또는 교체합니다.
3. `배포 → 배포 관리 → 수정 → 새 버전 → 배포`합니다.
4. 기존 웹앱 URL은 그대로 사용할 수 있습니다.

## 자동 생성되는 모아 전용 시트
- `모아_대화`: 관리자/수동 승인형 공용 대화 데이터
- `모아_표현학습`: 실제 반응이 좋았던 표현-답변 연결 강도
- `모아_학습후보`: 사용자 정정 후보. 자동 승인하지 않음
- `모아_개인기억`: 좋아하는 것/싫어하는 것/별명/취미처럼 제한된 사용자별 기억
- `모아_반응학습`: 여러 사용자에게 검증된 신조어·채팅 반응 의미
- `모아_주제학습`: 대화 원문 없이 핵심 소재와 연관소재/행동/감정의 공출현 관계

기존 미나용 `대화` 시트는 읽거나 쓰지 않습니다.

## 자연대화 처리 순서
1. 타이머/알람/계산/단위변환/랜덤/가위바위보 같은 로컬 도구
2. 순수 맞장구·웃음·감사·정정 반응 판별
3. 개인기억 질문
4. 날씨/공기질/환율/뉴스/일반검색 등 검색 보조
5. 검증된 공용 표현학습 답변 및 주제 관계 힌트 조회
6. 소재 + 행동 + 결과 + 감정 + 최근 사람/주제 문맥을 이용한 공통 대화 플래너
7. 초기 builtin 회화 및 안전 fallback

`ㅋㅋ`가 문장 안에 들어갔다고 무조건 직전 모아 답변의 웃음 피드백으로 처리하지 않습니다. 순수 반응 문장인지 먼저 확인합니다.

## 반응 학습 안전장치
- `ㅇㅇ`, `ㅇㅋ`, `맞음`, `그치`, `인정`, `ㅋㅋ`, `ㄱㅅ`, `ㄴㄴ`, `아님`, `노잼` 등 실제 채팅체를 넓게 인식합니다.
- 명시적 정정/부정은 긍정보다 우선합니다.
- `맞음?`, `ㄹㅇ?`, `글쎄`처럼 불확실한 표현은 긍·부정 점수에 억지로 넣지 않습니다.
- 일반 단어를 `오리≈오키`처럼 오인하던 편집거리 추정은 사용하지 않습니다. 흔한 오타는 명시적 alias로만 처리합니다.
- 새 반응표현은 여러 사용자/여러 문맥 증거가 충분한 경우에만 active로 승격합니다.
- 이해용 신조어 사전과 모아가 실제로 출력하는 말투는 분리합니다.

## 주제/관계 학습
- 클라이언트가 짧은 핵심 소재를 최대 4개 추출합니다.
- 서버에는 대화 원문 대신 `소재`, `함께 등장한 소재`, `행동 유형`, `감정 방향`, `의도`만 전송합니다.
- 같은 사용자의 반복은 사용자 해시 1표로 제한합니다.
- 소재 자체는 서로 다른 사용자 3명 이상에게 관찰돼야 공용 active 관계로 사용합니다.
- 연관소재는 서로 다른 사용자 2명 이상에게 같은 관계가 관찰된 경우에만 대화 힌트로 반환합니다.
- 따라서 코드 작성 시점에 없던 새 소재도 사용량이 쌓이면 관계망이 생길 수 있지만, 한 사람의 반복으로 공용 지식처럼 굳지 않습니다.

## 검색/보조 기능
- 일반 지식: Wikipedia + DuckDuckGo 공개 응답, 부족하면 Google SafeSearch 링크
- 날씨/기온: Open-Meteo
- 미세먼지/공기질: Open-Meteo Air Quality
- 환율: Frankfurter
- 최신 소식: Google News RSS
- 도시 현지시간: Open-Meteo geocoding timezone
- 바로가기: YouTube, 네이버/Google 검색, 네이버/Google 지도, 이미지 검색, 네이버 사전
- 시점에 따라 바뀌는 검색 결과는 자연학습 답변으로 승격하지 않습니다.

## 자동 정리
달력 날짜가 오래됐다는 이유만으로 학습 데이터를 삭제하지 않습니다. 실제 모아 서버 상호작용 serial이 충분히 증가한 뒤에도 약한 자동후보만 `candidate → dormant → delete` 2단계로 정리합니다.

자동정리 대상:
- 약한 `모아_표현학습`
- 미검증 `모아_학습후보`
- 증거가 거의 없는 `모아_반응학습`
- 서로 다른 사용자 지지가 1명 이하인 약한 `모아_주제학습`

보호:
- `모아_대화` 확정/수동 데이터
- `모아_개인기억`
- review/approved/protected/pinned 데이터
- 충분한 사용자 지지를 받은 active 반응/주제 데이터

주 1회 유지보수를 쓰려면 `moaInstallMaintenanceTrigger_()`를 한 번 실행합니다. 제거는 `moaRemoveMaintenanceTrigger_()`입니다.

## 완전 제거 방법
1. Apps Script에서 `MOA_CHAT.gs`, `MOA_LEARNING.gs` 삭제
2. `Code.gs`의 `MOA_CHAT_INTEGRATION_START` ~ `MOA_CHAT_INTEGRATION_END` 블록 삭제
3. 웹앱 새 버전 재배포
4. 필요하면 모아 전용 6개 시트를 삭제
5. 클라이언트에서 `js/ai/moa-dialogue-core.js`, `js/ai/moa-chat-engine.js`, `js/features/moa-chat.js`, `css/features/moa-chat.css`와 연결 마커를 제거

기존 미나 기능과 Firebase는 건드릴 필요가 없습니다.
